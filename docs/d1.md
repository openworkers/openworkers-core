# D1 binding: compatibility with Cloudflare D1

This file is the contract of the D1 binding. The runtimes build the guest
API from it, the runner implements it, and the conformance tests check it.

Reference: the Cloudflare D1 Worker API pages, read on 2026-10-11:

- https://developers.cloudflare.com/d1/worker-api/d1-database/
- https://developers.cloudflare.com/d1/worker-api/prepared-statements/
- https://developers.cloudflare.com/d1/worker-api/return-object/
- https://developers.cloudflare.com/d1/worker-api/

Status values:

- **same**: the documented Cloudflare behavior.
- **chosen**: Cloudflare does not document it; this file sets the behavior.
- **different**: the behavior is not the Cloudflare one, for the reason given.
- **rejected**: the call throws an error.

## Wire format

The runtime sends one `D1Op` per guest call and receives one `D1Result`
(`src/ops/d1.rs`).

| Guest call | `D1Op` |
| --- | --- |
| `stmt.all()`, `stmt.run()`, `stmt.raw()` | `query` with `rows: "all"` |
| `stmt.first()`, `stmt.first(column)` | `query` with `rows: "first"` |
| `db.batch(statements)` | `batch` |
| `db.exec(sql)` | `exec` |

`prepare` and `bind` do not call the runner. They build a statement object
in the runtime.

## D1Database

| Method | Status | Behavior |
| --- | --- | --- |
| `prepare(sql)` | same | Returns a statement. No call to the runner. |
| `batch(statements)` | same | One transaction. A failure rolls back every statement, and the promise rejects. The result is one `D1Result` per statement, in order. |
| `batch([])` | chosen | Resolves to `[]` without a call to the runner. |
| `batch` with a statement of another binding | chosen | Throws `TypeError` before the call. |
| `exec(sql)` | different | Statements are split by the SQLite parser, so one statement can use several lines and a string can contain `;`. Cloudflare documents a split on new lines. Each statement commits on its own. Execution stops at the first error; the statements before it stay committed. Returns `{ count, duration }`. |
| `exec` with parameters (`?`) | chosen | `D1_ERROR`; exec has no binding. |
| `withSession()` | rejected | No read replicas. |
| `dump()` | rejected | Cloudflare supports it only for alpha databases. |

## D1PreparedStatement

| Method | Status | Behavior |
| --- | --- | --- |
| `bind(...values)` | same | Returns a new statement. The original statement is not changed, so a statement bound twice in one batch keeps both parameter sets. |
| `?NNN` parameters | same | `?1` takes the first value. |
| `?` parameters | same | SQLite numbering: one more than the largest number used before. |
| `:name`, `@name`, `$name` | same | `D1_ERROR`: Cloudflare supports ordered and anonymous parameters only. |
| Fewer or more values than parameters | chosen | `D1_RANGE_ERROR` before execution. |
| `run()` | same | Same result as `all()`. |
| `all()` | same | `D1Result` with every row as an object. |
| `first()` | same | The first row as an object, or `null` when there is no row. |
| `first(column)` | same | The value of the column in the first row, or `null` when there is no row. Throws `D1_ERROR` when there is a row and the column does not exist. |
| `raw()` | same | An array of row arrays, columns in SQL order. |
| `raw({ columnNames: true })` | same | The first array is the column names. |
| `raw({ columnNames: true })`, no row | chosen | `[columnNames]`. |
| Duplicate column names | chosen | `raw()` keeps every value. In `all()` and `first()`, the last column with a name sets the value of that key. |

## D1Result

| Field | Status | Value |
| --- | --- | --- |
| `success` | same | `true`. A failure rejects the promise. |
| `results` | same | Row objects. `[]` when the statement returns no row. |
| `meta.duration` | same | SQLite execution time in milliseconds. |
| `meta.timings.sql_duration_ms` | same | Same as `meta.duration`. |
| `meta.changes` | same | `sqlite3_changes` after the statement. |
| `meta.last_row_id` | same | `sqlite3_last_insert_rowid`. |
| `meta.changed_db` | different | `true` when the statement is not read-only, also when it changes no row. |
| `meta.size_after` | same | Database size in bytes after the statement. |
| `meta.served_by_primary` | same | `true`: one copy serves reads and writes. |
| `meta.total_attempts` | same | `1`: the runner does not retry. |
| `meta.rows_read`, `meta.rows_written` | different | Absent. SQLite does not count scanned rows, and the runner does not report an estimate. |
| `meta.served_by`, `meta.served_by_region` | different | Absent. No Cloudflare backend or region. |

## Values

| JavaScript to SQLite | Status | Behavior |
| --- | --- | --- |
| `null` | same | `NULL` |
| Number, safe integer | same | `INTEGER` |
| Number, other | same | `REAL` |
| String | same | `TEXT` |
| Boolean | same | `INTEGER` 1 or 0 |
| `ArrayBuffer`, `ArrayBufferView` | same | `BLOB`. Sent as bytes, not as a number array. |
| `undefined` | same | `D1_TYPE_ERROR` |
| BigInt, object, function, symbol | chosen | `D1_TYPE_ERROR` |

| SQLite to JavaScript | Status | Behavior |
| --- | --- | --- |
| `NULL` | same | `null` |
| `INTEGER` | same | Number. Precision is lost above `Number.MAX_SAFE_INTEGER`. |
| `REAL` | same | Number |
| `TEXT` | same | String |
| `BLOB` | same | Array of numbers (`Array.from` of the bytes) |

## SQL

| Item | Status | Behavior |
| --- | --- | --- |
| `BEGIN`, `COMMIT`, `ROLLBACK`, `SAVEPOINT`, `RELEASE` | chosen | `D1_ERROR`. Use `batch` for a transaction. |
| `ATTACH`, `DETACH` | chosen | `D1_ERROR` |
| `load_extension` | chosen | `D1_ERROR` |
| `PRAGMA` read-only schema pragmas | chosen | Allowed: `table_list`, `table_info`, `table_xinfo`, `index_list`, `index_info`, `index_xinfo`, `foreign_key_list`, `foreign_key_check`, `quick_check`. |
| `PRAGMA defer_foreign_keys` | chosen | Allowed; migration tools use it. |
| Other `PRAGMA` | chosen | `D1_ERROR` |
| Foreign keys | same | Enforced. |

## Errors

The guest receives an `Error`. Its message starts with the D1 prefix, then
the SQLite message and code, as in Cloudflare: `D1_ERROR: no such table:
users: SQLITE_ERROR`. Messages never contain file paths.

| `D1ErrorKind` | Message prefix | Meaning |
| --- | --- | --- |
| `sql` | `D1_ERROR` | SQLite rejected the statement. Its transaction rolled back. |
| `type` | `D1_TYPE_ERROR` | A value has an unsupported type. Nothing ran. |
| `range` | `D1_RANGE_ERROR` | The number of values does not match the parameters. Nothing ran. |
| `interrupted` | `D1_ERROR` | The deadline stopped the statement. Its transaction rolled back. |
| `overloaded` | `D1_ERROR` | The runner refused the call before running it. A retry later can succeed. |
| `unavailable` | `D1_ERROR` | The binding has no usable database. |

In a batch or an exec, `statement` is the index of the failing statement.

## Limits

Start values. The runner makes them configurable.

| Limit | Value | Cloudflare |
| --- | --- | --- |
| SQL statement length | 100000 bytes | same |
| Bound parameters per statement | 100 | same |
| Columns per table | 100 | same |
| String, BLOB or row size | 2000000 bytes | same |
| Result of one statement | 16 MiB | not documented |
| Database size | 500 MiB | different (10 GB) |
| Statement duration | 30 seconds, or less when the worker deadline is earlier | same |
